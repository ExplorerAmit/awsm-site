# awsm (awsm.im) website

## Brand and logo: follow strictly
The brand rules are in brand/AI-INSTRUCTIONS.md and are loaded below.
File paths in that guide are relative to the brand/ folder
(e.g. awsm/svg/awsm-horizontal-on-light.svg = brand/awsm/svg/awsm-horizontal-on-light.svg).

@brand/AI-INSTRUCTIONS.md

Key rules for this codebase:
- Header and footer use the main logo "awsm" (lowercase), never "awsm.im". The web address is plain text.
- Use the exact symbol SVG from the brand guide or files in brand/; never redraw, approximate or regenerate the logo.
- Colours: powder blue #8CAFCD, deep blue #3A5F80, ink #14161A, paper #F6F3EE. No amber/orange (#F2A93B is an old draft colour).
- Never put powder-blue text on light backgrounds; use #3A5F80.
- Favicon, app icons and og:image come from brand/icon/ and brand/social/; copy them into the site's images/ folder rather than creating new ones.
- When unsure about any logo or colour choice, ask before changing it.
