awsm brand kit
==============

Two versions of one logo, both lowercase:

  awsm       MAIN LOGO. Identity: signage, website header/footer, visiting
             cards, stationery, profile pictures. If unsure, use this.
  awsm.im    WEB-ADDRESS LOGO. Promotion: posters, flyers, banners, social
             posts and ads, link previews, event and tie-up material.
  Never use both on the same item.

Colours
  Powder blue  #8CAFCD   symbol tile; .im on dark; accents on dark
  Deep blue    #3A5F80   .im on light; links/accent text on light
  Ink          #14161A   m and dot; wordmark on light; dark backgrounds
  Paper        #F6F3EE   wordmark on dark; light backgrounds
Type: Bricolage Grotesque ExtraBold, lowercase, -3.5% letter-spacing.
      Body text: Inter. (All logo SVGs are outlined; no fonts needed.)

Folders
  awsm/            main logo: horizontal, stacked, wordmark, one-colour (SVG + PNG)
  awsm-im/         web-address logo: same set (SVG + PNG)
  icon/            app icon, favicon, symbol-only files
  signage-cutout/  PHYSICAL SIGNAGE ONLY: m and dot cut out of the tile,
                   single compound path for laser cutting, etching, vinyl,
                   CNC or debossing. Never use on screen or in print documents.
  social/          link-preview image (1200x630, uses awsm.im)
  website/         drop-in site files: index.html + favicon.ico at the site
                   root; images/ contents into the site's images/ folder

AI-INSTRUCTIONS.md
  Paste into any AI tool (Claude, ChatGPT, Canva AI...) before asking it to
  design or code anything for awsm. It holds the exact rules, colours,
  symbol code, file choices and a prompt template for image generators.
